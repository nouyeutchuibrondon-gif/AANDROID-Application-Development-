📋 WHAT IS THIS?
═══════════════════════════════════════════════════════════════════════════════
A command-line tool that converts Excel files with student marks to letter grades.

Run from Windows Command Prompt / PowerShell / Any Terminal

✓ Java 17 - Already installed on your system
✓ Standalone - No Android required
✓ Fast - Processes 1000+ students quickly

═══════════════════════════════════════════════════════════════════════════════

🚀 3-STEP SETUP
═══════════════════════════════════════════════════════════════════════════════

📥 STEP 1: Download Gradle 8.5
   └─ https://gradle.org/releases/
   └─ Download: gradle-8.5-all.zip (~330 MB)
   └─ Extract to StudentGradesFixed\ folder
   └─ Result: StudentGradesFixed\gradle-8.5\

🔨 STEP 2: Build the App
   └─ Open Command Prompt in StudentGradesFixed folder
   └─ Run: gradle-8.5\bin\gradle.bat console-app:build -x test
   └─ Wait 2-3 minutes...
   └─ Look for: "BUILD SUCCESSFUL"

✅ STEP 3: Test It
   └─ Run: run-console-app.bat students.xlsx
   └─ Check: StudentGrades_Output.xlsx

═══════════════════════════════════════════════════════════════════════════════

💾 EXCEL INPUT FORMAT
═══════════════════════════════════════════════════════════════════════════════

Your Excel file must look like this:

   ┌─────────────┬────────┐
   │ Name        │ Marks  │   ← Header row (row 1 - skipped)
   ├─────────────┼────────┤
   │ Alice       │ 85     │
   │ Bob         │ 72     │
   │ Charlie     │ 95     │
   │ Diana       │ 60     │
   └─────────────┴────────┘

IMPORTANT:
  • Column A = Student Names
  • Column B = Marks (numbers 0-100)
  • First row = Header (will be skipped)
  • No empty rows in middle

🎯 USAGE EXAMPLES
═══════════════════════════════════════════════════════════════════════════════

Method 1: Batch Script (Easiest)
────────────────────────────────
   run-console-app.bat students.xlsx
   run-console-app.bat "C:\Users\John\Downloads\marks.xlsx"
   run-console-app.bat ..\folder\grades.xlsx

Method 2: Direct Command
────────────────────────
   java -jar console-app\build\libs\console-app.jar students.xlsx

Method 3: PowerShell
────────────────────
   .\run-console-app.ps1 -ExcelFile "students.xlsx"

❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ERROR: "Could not find main class"
→ JAR not built yet. Run Step 2 (gradle build command)

ERROR: "File not found"
→ Check path is correct, use full path like: C:\Users\John\Downloads\marks.xlsx

ERROR: "No valid data found"
→ Check Excel format:
  • Column A = Names
  • Column B = Numbers
  • Starts from row 2 (row 1 is header)

BUILD FAILS: "Gradle execution failed"
→ Try: gradle-8.5\bin\gradle.bat clean console-app:build -x test

💡 TIPS
═══════════════════════════════════════════════════════════════════════════════

1. Keep the JAR file location: console-app\build\libs\console-app.jar
   → Or modify PATH to point to it

2. Test with small file first (~10 students)

3. Once built, the JAR never changes unless you modify the code

4. Can copy JAR to other computers (need Java installed)

5. For large files (10K+ students):
   java -Xmx2048m -jar console-app\build\libs\console-app.jar large.xlsx
   (Allocates more memory to Java)
