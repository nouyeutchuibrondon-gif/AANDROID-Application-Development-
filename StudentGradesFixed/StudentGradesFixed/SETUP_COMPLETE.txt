🎯 HOW TO USE (3 STEPS)
════════════════════════════════════════════════════════════════════════════════

STEP 1: GET GRADLE
─────────────────────────────────────────────────────────────────────────────
Download Gradle 8.5 from: https://gradle.org/releases/
  • Download: gradle-8.5-all.zip (about 330 MB)
  • Extract to: StudentGradesFixed\ folder
  • One-time setup


STEP 2: BUILD THE APP
─────────────────────────────────────────────────────────────────────────────
Open Command Prompt in StudentGradesFixed folder and run:

  gradle-8.5\bin\gradle.bat console-app:build -x test

  • Wait 2-3 minutes for build to complete
  • Look for: "BUILD SUCCESSFUL"
  • Creates: console-app\build\libs\console-app.jar


STEP 3: USE THE APP
─────────────────────────────────────────────────────────────────────────────

Option A (Easiest):
  run-console-app.bat students.xlsx

Option B (Direct command):
  java -jar console-app\build\libs\console-app.jar students.xlsx

Option C (With full path):
  java -jar "C:\path\to\console-app\build\libs\console-app.jar" marks.xlsx

📊 INPUT/OUTPUT FORMAT
════════════════════════════════════════════════════════════════════════════════

INPUT EXCEL FILE (students.xlsx):
┌─────────────────┬────────┐
│ Name            │ Marks  │ ← Header row (will be skipped)
├─────────────────┼────────┤
│ Alice Johnson   │ 85     │
│ Bob Smith       │ 72     │
│ Charlie Brown   │ 95     │
│ Diana Prince    │ 60     │
│ Eve Davis       │ 48     │
└─────────────────┴────────┘

OUTPUT EXCEL FILE (StudentGrades_Output.xlsx):
┌──────────────────┬────────┬────────────────┐
│ Student Name     │ Marks  │ Grade          │
├──────────────────┼────────┼────────────────┤
│ Alice Johnson    │ 85     │ A (Very Good)  │
│ Bob Smith        │ 72     │ B (Good)       │
│ Charlie Brown    │ 95     │ A+ (Excellent) │
│ Diana Prince     │ 60     │ C (Average)    │
│ Eve Davis        │ 48     │ F (Fail)       │
└──────────────────┴────────┴────────────────┘

GRADE SCALE:
A+ = 90-100 (Excellent)
A  = 80-89  (Very Good)
B  = 70-79  (Good)
C  = 60-69  (Average)
D  = 50-59  (Pass)
F  = 0-49   (Fail)

❓ COMMON QUESTIONS
════════════════════════════════════════════════════════════════════════════════

Q: Where do I start?
A: Open START_HERE.txt - it has 3 simple options to choose from

Q: Do I need Android Studio?
A: No, completely optional. You can build with Gradle command line.

Q: What if gradleFails to download?
A: Download gradle-8.5-all.zip manually from https://gradle.org/releases/

Q: Can I use this on Mac/Linux?
A: Yes! Same process, just use gradle-8.5/bin/gradle instead of gradle.bat

Q: How long does build take?
A: First time: 2-3 minutes (downloading dependencies)
   Subsequent: 30 seconds

Q: Can I copy the JAR to another computer?
A: Yes! Copy console-app\build\libs\console-app.jar to any computer with Java

Q: What if my Excel format is wrong?
A: See CONSOLE_APP_SETUP.md - has exact format examples

Q: Can I modify the grade scale?
A: Yes, edit MainConsole.kt calculateGrade() function and rebuild
